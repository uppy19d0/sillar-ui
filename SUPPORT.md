# Support

Use [GitHub Discussions](https://github.com/uppy19d0/sillar-ui/discussions) for implementation questions and ideas. Use [GitHub Issues](https://github.com/uppy19d0/sillar-ui/issues) for reproducible defects and accessibility problems.

Include the Sillar UI version, React version, browser, expected behavior, actual behavior, and a minimal reproduction. Accessibility reports should also describe the input method and assistive technology when relevant.

Security reports follow the private process in `SECURITY.md`.
